# Legal notice: this software is not for piracy

> # ⛔ rtorrent-mcp is NOT a piracy tool.
> **This software does not help with copyright infringement. It ships no
> infringing content, recommends no infringing sources, and configures
> nothing for infringing purposes.** BitTorrent is a neutral distribution
> protocol with real lawful uses (see below) — this repo exists for those,
> and for operating your own client and your own media pipeline. Questions
> asking where to download infringing content, which indexers or groups to
> use, or how to configure anything here *for* infringement will be
> **respectfully declined and the issue closed** (see §5 below).
> That stance is permanent and not up for discussion in issues.

## What this software is

rTorrent (a lightweight, scriptable BitTorrent client) driven over XML-RPC,
with search integrations, post-processing into Plex/Jellyfin libraries, and
a dashboard — plus a built-in `legal_management` tool (`risk`, `check`,
`advice`, `status`) that assesses download risk with Austrian context. The
tool and the docs describe risk; they do not grant permission.

## 5. Issue policy: sourcing questions get declined and closed

So nobody has to improvise in the moment, this is the standing policy for
this repo's issue tracker:

> **Questions asking where to download infringing content — "where do I
> point my torrent app," "best indexer for X," "which release group,"
> invite requests, tracker configuration for infringing purposes — will be
> respectfully declined and the issue closed.** A maintainer replies with a
> short pointer to [lawful sourcing](LEGAL_SOURCING.md) and closes. No
> debate, no exceptions, no second chances on the same question. This
> policy is itself documented here so closings never look arbitrary.

Copy-paste close reply: *"Thanks for asking — but this repo doesn't help
with sourcing infringing downloads (see docs/LEGAL_NOTICE.md §5). Lawful
uses are documented in docs/LEGAL_SOURCING.md. Closing."*
